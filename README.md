# ASP.NET sample for Azure App Service

This is an ASP.NET MVC web app that you can deploy to Azure App Service using Git. 

This code is the default MVC app as generated by 
[Visual Studio](https://www.visualstudio.com/products/visual-studio-community-vs).

To learn how to deploy this starter web app to App Service in a few minutes, go to 
[Get started with web apps in Azure App Service](https://azure.microsoft.com/en-us/documentation/articles/app-service-web-get-started/). 

## Deploy manually with GitHub Actions

The **Deploy to Azure App Service** workflow builds this ASP.NET Framework 4.8
application on Windows and deploys the published files to an existing Azure App
Service's production slot. It runs only when manually triggered; pushes and pull
requests do not deploy.

Prerequisites:

- An existing **Windows** Azure App Service configured for **ASP.NET v4.8**.
- The repository secret **`AZURE_CREDENTIAL`**, containing the existing service
  principal's JSON credentials with `clientId`, `clientSecret`, `subscriptionId`,
  and `tenantId`. The workflow passes this JSON directly to `azure/login`.
- The existing service principal must have permission to deploy to the target
  app, for example the Contributor role scoped to the app or its resource group.

The workflow does not create Azure resources, service principals, or secrets.

Once `.github/workflows/deploy-azure.yml` is on the repository's default branch,
open **Actions > Deploy to Azure App Service > Run workflow**. Select the branch
to deploy, enter the existing App Service name in **app-name**, and select
**Run workflow**. The app name is the Azure resource name, not its URL.
